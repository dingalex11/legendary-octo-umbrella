# [ARCHITECTURAL_REQUIREMENTS]
The application must support four distinct operational modes, dynamically spawned via a Room Factory pattern:
1. `[ONLINE_PRACTICE]`: Virtual buzzers over WebSockets. Requires NTP-style latency synchronization for fair lockouts.
2. `[IN_PERSON_PRACTICE]`: Bypasses network sync; relies on high-frequency local polling (USB buzzers/shared mic). Maximized UI text size for projector display.
3. `[MODERATED_TOURNAMENT]`: Strict Role-Based Access Control (RBAC). The server ignores player state transitions until the Moderator client sends cryptographic authorization. Requires granular manual overrides.
4. `[ISOLATION_DRILL]`: Solo single-player mode. Zero WebSockets. Client-side state authority. Uses Voice Activity Detection (VAD) to auto-trigger STT without manual clicks. Prefetches data in batches.
